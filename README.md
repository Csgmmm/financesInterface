# 💰 Personal Finance Tracker

A web application for managing personal finances. Easily track expenses, income, and recent transactions in real time with theme support (Light/Dark mode) and a fully responsive design.

---

## 🚀 Features

- **Transaction Management:** Quickly add income and expense entries.
- **History & Editing:** View recent transactions, update details/amounts, or delete entries via an edit modal.
- **Financial Summary:** Overview cards with real-time automatic balance and total calculations.
- **Light / Dark Mode:** Theme toggle with CSS variable adaptation.
- **Responsive Design:** Optimized layout for mobile, tablet, and desktop viewports.
- **Real-Time Database:** Secure data storage and synchronization powered by Firebase Firestore.

---

## 🛠️ Tech Stack

- **Frontend:** [React](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Build Tool:** [Vite](https://vitejs.dev/)
- **Styling:** CSS Modules (with dynamic CSS variables for theme switching)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Backend / Database:** [Firebase Firestore](https://firebase.google.com/)
